## 게임 규칙 전제 (코드 근거)

- 정확히 **5명**: 마피아 1 · 경찰 1 · 의사 1 · 시민 2 — `RoleManager.swift`, `GameRule.requiredPlayerCount`
- 상태 흐름: `Waiting → RoleAssigning → Introduction → [Mafia → Police → Doctor] →
  Discussion → Vote → (FinalDefense → ExecutionVote → ExecutionResult)? → Night(반복) | Result`
- 승리: 마피아 0명 → **시민 승** / 마피아 수 == 시민 수 → **마피아 승** — `ResultManager.checkWinner`
- 처형 가결: `2 × 찬성 > 투표 총수` (동수 = 부결) — `VoteManager.shouldBeExecuted`
- 페이즈 시간: 역할확인 55s · 자기소개 36s · 마피아 20s · 경찰 15s · 의사 14s ·
  토론 60s · 투표 25s · 변론 15s · 찬반 20s · 결과 7s — `GameTime.swift`
